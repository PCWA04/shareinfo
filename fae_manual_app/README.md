# FAE 維修手冊查詢助手（MVP）

這是一個純前端的靜態網頁工具，不需要安裝套件。

## 1) 啟動方式

在專案根目錄 `/workspace/shareinfo` 執行：

```bash
python3 -m http.server 8000
```

看到 `Serving HTTP on ...` 後，開啟瀏覽器：

- `http://localhost:8000/fae_manual_app/`

> 若你是遠端連線環境，請改用對應主機 IP：
> `http://<你的主機IP>:8000/fae_manual_app/`

## 2) 使用流程

1. 點選 **上傳 PDF 手冊**。
2. 等待「完成：檔名（共 X 頁）」訊息。
3. 在文字框輸入：
   - 機型
   - 錯誤碼
   - 現象
   - 最近異動
4. 點選 **查詢並引導排查**。
5. 查看：
   - 建議排查流程
   - 相關手冊頁碼與內容摘錄

## 3) 常見問題

### 無法載入 PDF
- 請確認檔案為可讀取文字的 PDF（若是掃描圖檔型 PDF，需先 OCR）。

### 查詢結果不準
- 請補充更具體資訊（錯誤碼、機型、發生時機）。

### 為什麼不能直接雙擊 `index.html`？
- 建議透過本機 HTTP 伺服器啟動，避免瀏覽器對模組與檔案載入的限制。
